# 인게임 손님 캐릭터 애셋 규격

이 문서는 손님 캐릭터를 생성하거나 `public/assets/core/customer/in-game-mapping/`에 반영할 때 반드시 지키는 최종 규격이다.

## 고정 캔버스

- 최종 파일: `1920×1080` 픽셀, `16:9`
- 파일 형식: sRGB PNG, straight alpha (`RGBA/BGRA`)
- 생성 검토본 `1672×941`은 검토용일 뿐 인게임 파일로 직접 사용하지 않는다.
- 최종 출력은 비율을 유지한 nearest-neighbor 변환과 투명 패딩으로 `1920×1080`에 맞춘다. 비균등 확대·축소 금지.

## 캐릭터 구도와 크기

- 손님은 카메라를 정면으로 바라본다. 좌우로 돌아간 3/4·측면 구도는 인게임 승인본으로 사용하지 않는다.
- 모든 손님은 좌석에 앉은 상태다. 서 있는 포즈, 걷는 포즈, 허리를 세운 선 자세는 금지한다.
- 캐릭터의 하단 중앙 착석 기준점과 눈높이를 세 상태에서 공유한다.
- 기준 영역은 1920×1080 화면에서 약 `324×432` 픽셀이다. 상태가 바뀌어도 캐릭터의 머리 높이·폭·착석 높이를 바꾸지 않는다.
- 머리, 손, 꼬치, 맥주잔은 캔버스 밖으로 잘리지 않는다.

## 필수 상태 3종

각 손님마다 다음 세 파일을 모두 만든다.

1. `waiting`: 양손을 허벅지에 둔 자연스러운 대기 상태
2. `eating-negima`: 정면 착석 상태에서 네기마 꼬치를 입에 가져간 상태
3. `drinking-beer`: 정면 착석 상태에서 생맥주잔을 입에 가져간 상태

상태 변경은 팔·손·입·소품만 수정한다. 얼굴, 헤어, 의상, 체형, 카메라, 착석 기준점은 세 파일에서 유지한다.

## 투명 배경과 금지 요소

- 배경은 완전 투명이어야 한다. 검은색/흰색 배경, checkerboard 패턴, 조명 후광, 바닥 그림자를 픽셀로 굽지 않는다.
- 캐릭터 애셋에는 테이블, 책상, 의자, 좌석 등받이, 바닥, 벽, 가게 배경을 포함하지 않는다. 게임 배경과 좌석은 런타임에서 합성한다.
- 대기 상태에는 음식과 잔을 넣지 않는다. 먹기 상태에는 네기마만, 음주 상태에는 생맥주잔만 허용한다.

## 반영 전 자동·수동 검수

- 이미지 크기 `1920×1080`인지 확인
- PNG에 alpha 채널이 있고 모서리 픽셀이 `alpha=0`인지 확인
- 정면 착석인지 확인
- 세 상태의 눈높이·하단 중앙 기준점·캐릭터 크기가 동일한지 확인
- 테이블·의자·배경·후광·그림자가 없는지 확인
- 파일명과 manifest의 `url`, `sha256`, `bytes`를 갱신

하나라도 실패하면 `in-game-mapping`에 승격하지 않고 `art-workspace/review` 후보로만 보관한다.
