# sources — 익힘 셰이더 프로토타입

`TECH-REND-001 §2.1` 익힘 셰이더의 첫 스파이크입니다.
꼬치를 클릭하면 **굽기 전(날것) ↔ 굽기 후(Perfect)** 로 전환됩니다.

## 실행

셰이더와 텍스처를 `fetch`로 불러오기 때문에 **로컬 서버가 필요합니다.**
`file://` 로 열면 CORS 때문에 동작하지 않습니다.

```bash
# app/ 디렉토리에서
python -m http.server 8777
```

브라우저에서 http://localhost:8777/sources/index.html

## 구성

```
sources/

```

## 셰이더 유니폼

| 유니폼 | 범위 | 의미 |
|---|---|---|
| `uDoneness` | 0~1 | 0 = 날것, 0.5 = Perfect, 1 = 탄 상태 |
| `uTareAmount` | 0~1 | 타레 도포량 → 광택 |
| `uTime` | 초 | 숯불 반사광 플리커 |
| `uTexSize` | px | 스페큘러용 텍셀 크기 |

프래그먼트 셰이더는 스펙대로 세 단계로 동작합니다.

1. **익힘 색 lerp** — 날것(분홍빛) → Perfect(마이야르 황갈색, 대비↑) → 탄 상태(암갈색)
2. **그을음 마스크** — fbm 노이즈, `uDoneness` 0.55부터 임계가 확장. 가장자리가 먼저 탐
3. **타레 스페큘러** — 텍스처 명도 기울기로 가짜 노멀을 만들어 Blinn-Phong 광택

## 알려진 한계

**`art/test.png`가 빈 흰색 원입니다.** 그래서 지금 보이는 것은 색 변화뿐이고,
타레 스페큘러는 사실상 보이지 않습니다 — 명도 기울기로 노멀을 만드는데
원본에 질감이 없어 기울기가 0입니다. 실제 꼬치 아트가 들어오면 광택이 살아납니다.

그 외 스펙 대비 미구현:

- **면별 독립 doneness** (`§2.1 앞/뒤면 분리`) — 지금은 단일 값. 뒤집기 판정 붙일 때 필요
- 3계층 씬, 카메라 앵글, VFX, 제스처 — 이 스파이크 범위 밖
