# 구현 검증용 참조 이미지

이 디렉터리는 `SCN-001` 구현을 직접 확인할 때 사용한 고정 화면 기록을 보존한다.
프로덕션 아트, 생성 reference 또는 `public/assets` 런타임 입력이 아니다.

## 보존 세트

- `scn-001/manual-qa-v1/`: 2026-07-21 공정 10단계 × `1280×720`, `1920×1080` 수동 검증 기록 20장
- `scn-001/e2e-state-v2/`: 2026-07-25 핵심 상태 8단계 × 두 Playwright viewport 기록 16장

이미지는 기존 app 이력과 로컬 검증 증빙에서 바이트 변경 없이 복원했다.
`SHA256SUMS`가 파일·해시·규격·세트별 수량을 고정하며 다음 명령으로 검사한다.

```bash
npm run visual:references:validate
```

이 파일들은 자동 pixel-diff golden이 아니다. 구현 변경의 시각적 의미를 사람이 비교하는
고정 참조이며, 새 기준으로 교체하려면 변경 사유와 검증 범위를 함께 기록한다. Playwright가
실행 중 생성하는 새 캡처는 계속 `test-results/`에 출력하고 Git에 추적하지 않는다.
